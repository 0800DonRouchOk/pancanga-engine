# Campaign 55.0: Knowledge Acquisition & Authoring

Status: ACTIVE

Phase: Knowledge Library population

## Mission Change

The infrastructure of Pancanga Engine is considered mature enough to begin
structured content work.

From this campaign onward, the primary objective is no longer to create new
architecture, schemas, registries, or policy documents.

The primary objective is:

```text
Acquire, verify, structure, and publish traceable observance knowledge.
```

## Authoring Workflow

For each observance:

```text
1. Identify available accepted sources.

2. Extract relevant information.

3. Classify each source according to KB-REF-001.

4. Record provenance.

5. Complete the JSON entry according to observance.schema.json.

6. Apply KB-OBS-001 editorial discipline.

7. Mark unsupported sections as pending.

8. Review source alignment.

9. Approve only when every claim is traceable.

10. Publish only after review and approval.
```

## Prohibited Content

It is forbidden to:

```text
invent doctrine
invent narrative details
invent benefits
complete gaps with memory
complete gaps with unsourced summaries
write devotional claims without source support
write procedural instructions without source support
mark pending content as complete
```

## Pending Policy

If a section cannot be supported from accepted sources, it must remain explicit:

```text
pending
```

Preferred wording:

```text
Contenido pendiente de estructurar desde fuentes locales aprobadas.
```

## Golden Sample

The first authored observance must function as the editorial golden sample.

Selection criteria:

```text
strong source availability
clear narrative
minimal calendrical controversy
clear provenance
clear review path
```

The golden sample should prove the entire authoring pipeline:

```text
sources collected
↓
sources classified
↓
content drafted
↓
provenance completed
↓
reviewed
↓
approved
↓
published
```

After the golden sample is approved, the same standard may be applied to the
remaining observances.
