# Janmāṣṭamī Technical Source Record

Campaign: 61.0W  
Scope: month nomenclature and niśītha operationalization

These works are Tier 4 technical bibliography. They clarify calendar terms
used by the Janmāṣṭamī rule but do not replace Hari-bhakti-vilāsa or the
Dig-darśinī-ṭīkā as normative authorities.

Article 51 explains that, in the pūrṇimānta system, the dark fortnight bears
the name of the following amānta month. This supports nomenclature mapping
only; it does not select the Janmāṣṭamī date.
